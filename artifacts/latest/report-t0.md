## 发现并修复的缺陷

| 等级 | 缺陷 | 根因 | 修复 |
|---|---|---|---|
| **P1** | 同图不同问法返回旧答案（缓存污染，命中 §4.6 视觉记忆污染场景） | 缓存 key 只含图片 hash 不含问题 | key = hash(图片+问题+模式) ✅ |
| **P2** | 视觉 API 空输出被写入缓存 → 永久空结果 | 空输出被当成功 | 空输出不缓存、计入失败计数 ✅ |
| **P2** | 批量连续调用触发免费 API 限流（29 次连续调用 3 次失败） | GLM 免费 1 并发 | 测试侧指数退避重试；链路侧已有熔断 |
| **P3** | 测试夹具倾斜图文字旋出画布（纯白图） | 生成器 rotate+paste 裁剪错误 | 居中绘制+中心裁剪 ✅ |

## 已知缺陷（未修复，P1/P2）

1. **结构化输出不达标**（方案 §2.3）：当前 JSON 仅 `{provider, text}`，缺 bbox/confidence/elements/relations/warnings —— 需在视觉层 prompt 结构化 + 解析层实现
2. **无可观测性**（§2.6）：无 trace_id/request_id/阶段耗时/重试日志
3. **注入防护无硬隔离**（§6）：识别层正确转录注入文字，但无 `content_type: untrusted_visual_text` 标记；DeepSeek 层仅依赖规则约束（CLAUDE.md），无程序化隔离
4. **多图片/帧支持缺失**（§4.6）：一次一图，无多图对比能力
5. **未覆盖输入**：GIF 帧、WebP、EXIF 旋转、超大图（>5MB 直接拒绝，符合预期但未测边界）
